# MacAngioView

**The MacAngioView beta is over.** Its successor, **CardiacStudy: DICOM
Viewer**, plays cath, echo, CT and MR studies on Mac and Windows, and is
available only from the stores:

- Mac: [Mac App Store](https://apps.apple.com/app/id6824492948) (macOS 15 or later)
- Windows: Microsoft Store release coming soon, as CardiacStudy Player (Windows 10 1809 or later, or Windows 11, 64-bit)

More about the app: [williamshillsoftware.com](https://williamshillsoftware.com/cardiacstudy-player/)
· Support: support@williamshillsoftware.com

served by GitHub Pages (`CNAME`, `.nojekyll`).
